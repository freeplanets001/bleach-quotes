# BLEACH 名言集 ― 黒と白の言葉たち

BLEACHの名言を、雰囲気イラストと一緒に全画面で味わう非公式ファンアプリです。
名言は原作の巻・話を確認したものだけを収録しています（全14言）。

公開ページ: https://freeplanets001.github.io/bleach-quotes/

- 画像の一部はファン企画のキーフレーム再利用、その他は生成したオリジナルのファンアート風イラストです（公式絵・原作コマではありません）
- ソースコード: `~/workspace/dev/projects/bleach-quotes`（Vite + TypeScript）からビルドし、画像を data URI 化して配置しています
